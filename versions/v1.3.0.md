## 🎯 Objectif de la version

La phase **v1.2.0** a livré le pipeline de rendu frontend complet (Menu_Renderer, Location_Interceptor, Dynamic_CSS, Shortcode, Assets_Loader) ainsi que 7 widgets de base (`html`, `banner`, `custom_link`, `product_grid`, `category_grid`, `mini_cart`, `search`).

La **v1.3.0** enrichit la bibliothèque de widgets avec 4 nouveaux types orientés e-commerce et marketing, et upgrade 2 widgets existants pour les rapprocher des maquettes spec §5.9 :

| Widget | Statut | Spec | Description |
|--------|--------|------|-------------|
| `recent_posts` | Nouveau | §5.9.4 | Articles WordPress en grille (image, titre, date, extrait). |
| `social_icons` | Nouveau | §3.5, §5.7 | Icônes réseaux sociaux avec glyphes SVG inline. |
| `newsletter` | Nouveau | §5.7, §3.5 | Formulaire d'abonnement email avec AJAX. |
| `filters` | Nouveau | §3.5, §5.5 | Filtres WooCommerce layered nav. |
| `mini_cart` | Upgrade | §5.10 | Nouveau mode `display_mode: 'drawer'` (panneau latéral AJAX). |
| `search` | Upgrade | §5.9.5 | Nouvelle option `live_suggestions` (dropdown AJAX). |

## ✨ Nouveautés

### 1. 4 nouveaux widgets WooCommerce

#### 1.1 `recent_posts` — articles WordPress en grille

**Spec §5.9.4** : « Mini-grille de produits (image, prix, bouton panier). »

Bien que la spec l'illustre avec des produits, le widget `recent_posts` généralise le pattern aux articles de blog WordPress — utile pour les footers et les sidebars de contenu.

- **Settings** : `limit` (1-12), `columns` (1-4), `orderby` (`date`, `title`, `comment_count`, `rand`), `category` (ID ou vide), `show_image`, `show_date`, `show_excerpt` (booléens).
- **Cache** : transient 12 h, filtrable via `wtm_widget_cache_duration`.
- **Rendu** : `<div class="wtm-recent-posts">` contenant des `<article class="wtm-post-card">` (media 16:9 + body avec title 2-line clamp + date + extrait).

#### 1.2 `social_icons` — icônes réseaux sociaux

**Spec §3.5, §5.7** : « Icônes sociales » dans le footer.

- **Settings** : `items[]` (tableau de `{network, url, label?}`), `size` (12-64 px).
- **Glyphes SVG** : 7 réseaux prédéfinis rendus en CSS `mask-image` inline (pas de fichier externe) — Facebook, Twitter/X, Instagram, LinkedIn, YouTube, Pinterest, GitHub.
- **Couleurs hover par réseau** : Facebook → #1877F2, Twitter → #000000, Instagram → #E4405F, etc.
- **Rendu** : `<ul class="wtm-social-icons">` avec `<li>` contenant des `<a class="wtm-social-icon wtm-social-icon--{network}">`.

#### 1.3 `newsletter` — formulaire d'abonnement email

**Spec §5.7** : « Colonne 4 : Widget Newsletter (champ email + bouton "S'abonner" primaire). »

- **Settings** : `placeholder`, `button_label`, `provider` (`internal` | `mailchimp` | `none`), `list_id`, `success_message`, `layout` (`inline` | `stacked`).
- **Provider `internal`** : stocke les emails dans l'option `wtm_newsletter_subscribers` (dédupliqués, avec timestamp + IP anonymisée GDPR-friendly).
- **Provider `mailchimp`** : hook `wtm_newsletter_subscription_handled` permet à un plugin tiers d'appeler l'API Mailchimp et de bypass le stockage internal.
- **Provider `none`** : affiche juste le message de succès (utile pour démos / tests).
- **Submit** : admin-ajax `action=wtm_newsletter_subscribe`, nonce `wtm_newsletter`.
- **Hooks** :
  - `wtm_newsletter_subscription_handled` (filter) — court-circuite le stockage.
  - `wtm_newsletter_subscribed` (action) — déclenché après succès (pour sync CRM).

#### 1.4 `filters` — filtres WooCommerce layered nav

**Spec §3.5, §5.5** : « Menu vertical (sidebar navigation, filtres, menu catalogue). »

- **Settings** : `show_categories`, `show_price`, `show_attributes` (booléens), `attributes[]` (slugs d'attributs WC), `columns` (1-4).
- **Catégories** : `<select>` avec top 12 catégories triées par count.
- **Prix** : deux inputs `min_price` et `max_price` (number, step 0.01).
- **Attributs** : pour chaque slug dans `attributes[]`, récupère les terms de la taxonomy `pa_{slug}` et rend des checkboxes.
- **Submit** : GET vers la page Shop WC avec les query params standard (`?product_cat=…&min_price=…&max_price=…&filter_couleur=…`).

### 2. Widget `mini_cart` — mode drawer

**Spec §5.10** : « Compteur du panier : mise à jour dynamique avec une petite animation de rebond. »

Nouveau `display_mode: 'drawer'` qui transforme le widget en bouton ouvrant un panneau latéral fixe.

- **Settings ajoutés** : `display_mode` (`link` | `drawer`), `drawer_position` (`right` | `left`).
- **Comportement** : clic sur le bouton → JS frontend crée dynamiquement le drawer + overlay (si non présents), fetch la route REST `/wtm/v1/mini-cart-contents`, render les items (image, nom, quantité, prix), le total, et deux boutons "Voir le panier" + "Commander".
- **Interactions** : Escape ferme, clic overlay ferme, focus auto sur le bouton close, refresh auto du contenu quand les WC cart fragments sont mis à jour.
- **A11y** : `role="dialog"`, `aria-modal="true"`, `aria-expanded` sur le bouton trigger.

### 3. Widget `search` — suggestions live AJAX

**Spec §5.9.5** : « Suggestions de produits : liste déroulante avec image, nom, prix. Chargée via AJAX. »

Nouvelle option `live_suggestions: true` qui attache un listener `input` sur le champ de recherche.

- **Settings ajoutés** : `live_suggestions` (bool), `min_chars` (2-5, défaut 3).
- **Comportement** : debounce 250 ms, fetch la route REST `/wtm/v1/search-suggest?s=…&limit=5`, render un dropdown avec jusqu'à 5 produits (image thumbnail, titre, price_html, badge "Promo" si `on_sale`).
- **Navigation clavier** : ArrowDown/ArrowUp pour naviguer dans les suggestions, Escape pour fermer, role="listbox" sur le conteneur.
- **A11y** : `role="listbox"`, `role="option"` sur chaque suggestion, aria-label.

### 4. Routes REST publiques

#### `GET /wtm/v1/search-suggest`

- **Params** : `s` (string, required, min 2 chars), `limit` (int, 1-20, défaut 5).
- **Response** : `{ query, count, products: [{ id, title, permalink, price_html, thumbnail, on_sale }] }`.
- **Filter** : `wtm_search_suggest_query` pour modifier les args `wc_get_products()`.
- **Permission** : `__return_true` (les visiteurs non connectés doivent pouvoir rechercher).

#### `GET /wtm/v1/mini-cart-contents`

- **Params** : aucun.
- **Response** : `{ count, total, subtotal, items: [{ key, product_id, name, permalink, thumbnail, quantity, price_html }], cart_url, checkout_url, is_empty }`.
- **Permission** : `__return_true` (le panier est lié à la session WC, pas à l'utilisateur WP).

### 5. admin-ajax handler `wtm_newsletter_subscribe`

- **Hook** : `wp_ajax_wtm_newsletter_subscribe` + `wp_ajax_nopriv_wtm_newsletter_subscribe`.
- **Params POST** : `email`, `nonce`, `provider`, `list_id`.
- **Validation** : `check_ajax_referer('wtm_newsletter', 'nonce')` + `is_email()`.
- **Stockage** (provider `internal`) : option `wtm_newsletter_subscribers` (array d'entrées `{email, list_id, subscribed, ip}`).
- **IP anonymisée** : dernier octet IPv4 à 0, IPv6 tronquée à /64 — conformité GDPR.
- **Hooks** : `wtm_newsletter_subscription_handled` (filter, court-circuite le stockage) + `wtm_newsletter_subscribed` (action, post-subscription).

### 6. `WIDGET_SUBTYPES` picker dans le Builder

Quand l'utilisateur clique sur "Widget" dans le dropdown d'ajout d'item, un panneau secondaire s'ouvre avec les **12 sous-types** de widgets :

| Sous-type | Icône | Description |
|-----------|-------|-------------|
| `html` | `editor-code` | Contenu HTML personnalisé |
| `banner` | `format-image` | Image promo + lien |
| `custom_link` | `admin-links` | Lien CTA avec fond/couleur |
| `product_grid` | `products` | Mis en avant, ventes, nouveautés |
| `category_grid` | `category` | Catégories WooCommerce |
| `mini_cart` | `cart` | Lien ou drawer latéral AJAX |
| `search` | `search` | Barre de recherche produits + suggestions |
| `recent_posts` | `admin-post` | Articles du blog WordPress |
| `social_icons` | `share` | Liens réseaux sociaux |
| `newsletter` | `email` | Formulaire d'abonnement email |
| `filters` | `filter` | Filtres catégories, prix, attributs |
| `title` | `heading` | Petit titre dans une colonne |

Chaque sous-type a son propre jeu de defaults pour que l'item soit correctement configuré dès l'ajout (plus besoin de changer `widget_type` manuellement via PropertiesPanel).

### 7. Inspecteurs PropertiesPanel pour 7 widgets

Le panneau de propriétés a été étendu avec des formulaires d'édition complets pour :

- **`custom_link`** : label, url, couleur de fond, couleur du texte.
- **`mini_cart`** : mode d'affichage (link/drawer), position drawer (right/left), show_subtotal, show_checkout_button, show_thumbnail.
- **`search`** : placeholder, live_suggestions (bool), min_chars (2-5, conditionnel), show_category_filter.
- **`recent_posts`** : columns (1-4), limit (1-12), orderby (date/title/comment_count/rand), show_image, show_date, show_excerpt.
- **`social_icons`** : size (12-64 px), liste dynamique de réseaux avec inputs network + url + bouton supprimer, bouton ajouter.
- **`newsletter`** : placeholder, button_label, provider (internal/mailchimp/none), list_id, layout (inline/stacked), success_message.
- **`filters`** : show_categories, show_price, show_attributes + slugs d'attributs séparés par virgule (conditionnel).

### 8. CSS frontend (~570 lignes)

Nouvelles règles pour :

- **Drawer mini-cart** : `.wtm-cart-drawer` (position fixed, transform translateX, position right/left), header (background primary), body (scrollable), footer (border-top, boutons primary/secondary), overlay (rgba 0.45).
- **Suggestions dropdown** : `.wtm-search__suggestions` (absolute, opacity/transform transition), `.wtm-search__suggestion` (flex, hover bg), media+body layout, badge promo rouge.
- **Articles récents** : `.wtm-recent-posts` (grid auto-cols), `.wtm-post-card` (media 16:9, title 2-line clamp via -webkit-line-clamp, date + excerpt).
- **Icônes sociales** : `.wtm-social-icon` (flex circle, hover translateY -1px), 8 couleurs hover par réseau (Facebook, Twitter/X, Instagram, LinkedIn, YouTube, TikTok, Pinterest, GitHub), CSS mask-image inline pour 7 glyphes SVG.
- **Newsletter** : `.wtm-newsletter` (inline/stacked), email input + btn primary, message success/error avec border-left coloré.
- **Filtres WC** : `.wtm-filters` (flex column), `.wtm-filters__select`, price range (2 inputs + séparateur), checkboxes, actions (Filtrer primary + Réinitialiser secondary).
- **Responsive 768px** : drawer 100vw, recent_posts 1 colonne, newsletter inline → stacked, filters actions stacked.

### 9. JS frontend (~430 lignes)

Trois nouveaux modules initialisés dans `initAll()` :

- **`initCartDrawer()`** — création dynamique du drawer + overlay si non présents dans le DOM (avec header/body/footer), gestion ouverture/fermeture, fetch REST `/mini-cart-contents`, render items/total/actions, focus management, Escape close, refresh auto sur `wc_fragments_refreshed`.
- **`initLiveSearch()`** — debounce 250 ms, fetch REST `/search-suggest`, render dropdown avec image+title+price+badge promo, navigation clavier ArrowUp/Down/Escape, blur delay 200 ms pour permettre le clic sur suggestion.
- **`initNewsletter()`** — FormData POST vers `admin-ajax.php?action=wtm_newsletter_subscribe`, validation email client-side (regex), gestion états success/error avec classes CSS, reset form après succès, bouton disabled + label "Inscription…" pendant la requête.

## 🔒 Security

- **Nonce `wtm_newsletter`** vérifié sur le handler admin-ajax (mitigue spam cross-site).
- **IP anonymisée** (dernier octet IPv4 à 0, IPv6 tronquée à /64) pour les abonnés newsletter — conformité GDPR.
- **Échappement systématique** : `esc_url`, `esc_html`, `esc_attr`, `wp_kses_post` sur tout le rendu.
- **Slugs d'attributs** passent par `sanitize_title()`. **Réseaux sociaux** par `sanitize_html_class()`.
- **REST endpoints** : `permission_callback => '__return_true'` — les visiteurs non connectés doivent pouvoir utiliser le drawer et la recherche (panier lié à la session WC, pas à l'utilisateur WP).
- **Validation stricte** dans `Schema_Validator` pour les nouveaux widgets : limit (1-12), columns (1-6 ou 1-4), size (12-64), provider/layout enums, etc.
