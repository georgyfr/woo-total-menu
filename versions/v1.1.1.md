- **Date de sortie** : 2026-06-24
- **Statut** : ✅ Livrée
- **Tag Git** : [`v1.1.1`](https://github.com/georgyfr/woo-total-menu/releases/tag/v1.1.1)
- **ZIP de release** : [woo-total-menu-1.1.1.zip](https://github.com/georgyfr/woo-total-menu/releases/download/v1.1.1/woo-total-menu-1.1.1.zip)

## 🎯 Objectif de la version

Cette version rend le builder **pleinement opérationnel pour la création et l'édition d'items de menu**. L'utilisateur peut désormais :

- ✅ Ajouter des items (6 types) en racine ou en tant qu'enfants
- ✅ Supprimer des items (avec confirmation)
- ✅ Renommer un item inline (double-clic sur le label)
- ✅ Éditer toutes les propriétés d'un item selon son type
- ✅ Ajouter/éditer/supprimer des badges
- ✅ Éditer le titre du menu

Toutes les modifications sont immédiatement répercutées dans le state Redux et marquées comme "dirty" (●). Le bouton **Enregistrer** devient actif et sauvegarde via l'API REST.

## ✅ Nouveautés (Added)

### 1. Composant `AddItemButton` (nouveau fichier)

Bouton dropdown permettant d'ajouter un item parmi 6 types :

| Type | Icône | Description | Valeurs par défaut |
|------|-------|-------------|--------------------|
| `link` | `admin-links` | Un lien simple avec URL | `{ label: 'Nouveau lien', url: '#' }` |
| `mega_container` | `screenoptions` | Conteneur multi-colonnes | `{ label: 'Nouveau méga', children: [] }` |
| `column` | `columns` | Colonne (dans un méga) | `{ width: 6, children: [] }` |
| `widget` | `admin-generic` | Widget dynamique WooCommerce | `{ widget_type: 'html', widget_settings: { content: '<p>Nouveau widget</p>' } }` |
| `title` | `heading` | Titre de section | `{ label: 'Nouveau titre' }` |
| `separator` | `minus` | Séparateur visuel | `{}` |

**Caractéristiques** :
- 2 variantes : `compact` (icône seule) et full (icône + texte)
- Fermeture automatique au clic en dehors (via `useRef` + `useEffect`)
- Accepte `parentId` (null pour racine) et callback `onAdded`

### 2. Actions Redux dans le store `wtm/menu`

4 nouvelles actions pour manipuler les items :

```js
import { useDispatch } from '@wordpress/data';
const { addItem, updateItem, removeItem, moveItem } = useDispatch('wtm/menu');

// Ajouter un nouveau lien en racine
addItem({ type: 'link', label: 'Accueil', url: '/' }, null);

// Ajouter une colonne dans un mega_container
addItem({ type: 'column', width: 4 }, 'mega-1');

// Mettre à jour le label d'un item
updateItem('item-1', { label: 'Nouveau titre' });

// Supprimer un item (et tous ses enfants)
removeItem('item-1');

// Déplacer un item vers un nouveau parent à l'index 2 (préparé pour v1.1.2)
moveItem('item-1', 'mega-1', 2);
```

### 3. Helpers immutables pour la manipulation de l'arbre

Le store exporte 6 fonctions utilitaires pour manipuler l'arbre des items de façon immutable :

| Fonction | Description |
|----------|-------------|
| `generateId(prefix)` | Génère un ID unique : `prefix-{timestamp}-{counter}` |
| `findItem(items, id)` | Recherche récursive d'un item par ID |
| `mapItems(items, fn)` | Map récursif — retourner `false` pour supprimer |
| `updateItemById(items, id, patch)` | Met à jour un item par ID |
| `removeItemById(items, id)` | Supprime un item par ID (récursif) |
| `addChildToParent(items, parentId, newItem)` | Ajoute un enfant à un parent (ou en racine si parentId=null) |

### 4. TreePanel refondu

**Fonctionnalités** :
- **Bouton "+" en en-tête** : ajout d'item en racine (via `AddItemButton`)
- **Bouton "+" au survol** de chaque `mega_container` et `column` : ajout d'enfant
- **Bouton corbeille au survol** : suppression avec `confirm()` JavaScript
- **Double-clic sur le label** : passage en mode édition inline (input)
  - `Enter` pour valider
  - `Escape` pour annuler
  - Clic en dehors pour valider
- **Badge affiché** à côté du label si présent
- **Indicateur de sélection** : item sélectionné en violet (`#ede9fe`)
- **Footer avec bouton "Ajouter un élément"** quand la liste n'est pas vide
- **État vide** : message + bouton "Ajouter le premier élément"

### 5. PropertiesPanel refondu (édition complète par type)

Le panneau droit affiche maintenant un formulaire d'édition selon le type d'item sélectionné :

#### Pour `link` :
- Libellé (input text)
- URL (input text)
- Cible (select : `_self` / `_blank`)
- Icône (input text — nom ou URL SVG)
- Badge editor (text + color + background)
- Visibilité (select : `show` / `hide` / `show_on_mobile` / `hide_on_mobile`)

#### Pour `mega_container` :
- Libellé (input text)
- Déclencheur (select : `hover` / `click`)
- Largeur (input text — entier 200-2000 ou `"full"`)
- Badge editor
- Visibilité

#### Pour `column` :
- Largeur (input number 1-12)
- Visibilité

#### Pour `widget` :
- Type de widget (read-only, affiché en `<code>`)
- Libellé optionnel (input text)
- Settings selon le type de widget :
  - `html` → Contenu HTML (textarea)
  - `banner` → URL image, lien, texte alternatif
  - `product_grid` → Source (5 options : featured/best_selling/recent/on_sale/custom), colonnes (1-6), limite (1-12)
  - `category_grid` → Colonnes (1-6), afficher images (checkbox), afficher compteurs (checkbox)
- Visibilité

#### Pour `title` :
- Libellé (input text)
- Badge editor
- Visibilité

#### Pour `separator` :
- Visibilité (uniquement)

#### Si aucun item sélectionné mais menu chargé :
- Édition du **titre du menu** (input text avec onBlur)
- Slug (read-only)
- Statut (read-only)
- Type de menu (read-only)
- Emplacement (read-only)
- Version du schéma (read-only)
- ID (read-only)

### 6. Éditeur de badge

Composant dédié à l'édition des badges (utilisé pour `link`, `mega_container`, `title`) :

- Si pas de badge : bouton "+ Ajouter un badge"
- Si badge présent :
  - Texte (input text)
  - Couleur du texte (color picker — défaut `#FFFFFF`)
  - Couleur de fond (color picker — défaut `#6C5CE7`)
  - Bouton "Retirer le badge"

### 7. Styles CSS additionnels

~150 lignes de CSS ajoutées pour les nouveaux composants :

- `.wtm-add-item` + dropdown (positionné en absolu, ferme au clic dehors)
- `.wtm-tree__item-actions` (affichées au survol)
- `.wtm-tree__item-edit` (input inline pour renommage)
- `.wtm-tree__add-child` (zone d'ajout d'enfant)
- `.wtm-properties__row` inputs (text, number, select, textarea, color, checkbox)
- `.wtm-properties__badge-editor` (cadre gris pour l'éditeur de badge)
- `.wtm-properties__add-badge` (bouton dashed pour ajouter un badge)
