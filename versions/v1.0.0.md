## 🎯 Objectif de la version

Cette première version pose les **fondations techniques** du plugin : squelette PHP, autoloader PSR-4, classe centrale `Bootstrap`, gestion du cache, des permissions et des réglages globaux par défaut. Aucune fonctionnalité n'est encore visible côté utilisateur final, mais l'architecture est en place pour accueillir toutes les versions suivantes.

## ✅ Nouveautés (Added)

### 1. Squelette PHP et autoloader PSR-4
- Point d'entrée `woo-total-menu.php` avec entête WordPress standard
- Autoloader PSR-4 pour le namespace `WooTotalMenu\`
- Fonction helper `wtm()` pour récupérer le singleton `Bootstrap`
- Constantes globales :
  - `WTM_VERSION` = `1.0.0`
  - `WTM_PLUGIN_FILE`, `WTM_PLUGIN_DIR`, `WTM_PLUGIN_URL`, `WTM_PLUGIN_BASENAME`
  - `WTM_DB_VERSION` = `1`
  - `WTM_REST_NAMESPACE` = `wtm/v1`
  - `WTM_CPT_MENU` = `wtm_menu`
  - `WTM_OPTION_SETTINGS` = `wtm_global_settings`
  - `WTM_OPTION_TEMPLATES` = `wtm_user_templates`
  - `WTM_OPTION_DB_VERSION` = `wtm_db_version`

### 2. Classe `Bootstrap` (`src/Bootstrap.php`)
- Classe centrale orchestrant l'initialisation du plugin
- Vérification de dépendance (WooCommerce doit être actif, sinon notification admin)
- Chargement des traductions via `load_plugin_textdomain()`
- Hook `plugins_loaded` priorité 5 pour l'initialisation
- Méthodes statiques `on_activate()` / `on_deactivate()` branchées sur `register_activation_hook` / `register_deactivation_hook`
- Container de services : `wtm()->get('cache')`, `wtm()->get('permissions')`, etc.
- Actions `wtm_loaded` et `wtm_init` exposées aux développeurs tiers

### 3. Classe `Core\Cache_Manager` (`src/Core/Cache_Manager.php`)
- Wrapper unifié autour du cache objet WordPress (`wp_cache_*`) et des transients
- Groupe de cache dédié `wtm`
- Méthodes : `get()`, `set()`, `delete()`, `get_transient()`, `set_transient()`, `delete_transient()`
- Méthode `invalidate_menu($menu_id)` qui supprime tous les caches liés à un menu donné
- Sera utilisé par toutes les versions futures pour éviter les désérialisations JSON répétées

### 4. Classe `Core\Permissions` (`src/Core/Permissions.php`)
- 4 capacités personnalisées :
  - `wtm_manage_menus` — CRUD des menus
  - `wtm_manage_templates` — Gestion des templates
  - `wtm_view_analytics` — Lecture des analytics
  - `wtm_manage_settings` — Modification des réglages globaux
- Méthode `register_caps()` attribuant ces caps aux rôles qui ont déjà `manage_options`
- Méthode `remove_caps()` pour le nettoyage à la désinstallation
- Helpers `user_can($cap)` et `assert_can_manage_menus()`

### 5. Réglages globaux par défaut
- Option `wtm_global_settings` contenant 9 sections :
  - **general** : `enabled`, `default_location` (`primary`)
  - **styles** : `primary_color` (#6C5CE7), `background`, `text_color`, `success_color`, `error_color`, `border_radius` (6)
  - **typography** : `font_family` (Inter), `base_size` (14), `heading_size` (18)
  - **responsive** : `mobile_breakpoint` (768), `tablet_breakpoint` (1024), `mobile_behavior` (offcanvas), `hamburger_position` (right)
  - **performance** : `cache_enabled`, `lazy_load_widgets`, `minify_css`
  - **analytics** : `enabled` (false), `track_logged` (false)
  - **permissions** : `admin_default`, `editor_default`
  - **version** : `1.0.0`
  - **db_version** : `1`
- Option `wtm_db_version` = `1`

### 6. Page admin "À propos" (`src/Admin/Pages/About.php`)
- Menu top-level "Woo Total Menu" avec icône `dashicons-menu`
- Page d'accueil avec :
  - En-tête dégradé violet (couleur primaire #6C5CE7)
  - Liste des fonctionnalités de la version
  - Roadmap des versions à venir
  - Tableau d'information sur l'environnement (PHP, WP, WooCommerce, thème actif, DB version)
- Styles CSS en ligne (aucune dépendance externe)

### 7. `Frontend\Assets_Loader` (`src/Frontend/Assets_Loader.php`)
- Stub initial (no-op) — sera implémenté en v1.2.x
- Hook sur `wp_enqueue_scripts` priorité 20

### 8. Documentation
