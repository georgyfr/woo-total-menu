# Version 1.1.0 — Builder visuel React (squelette)

- **Date de sortie** : 2026-06-24
- **Statut** : ✅ Livrée
- **Tag Git** : [`v1.1.0`](https://github.com/georgyfr/woo-total-menu/releases/tag/v1.1.0)
- **ZIP de release** : [woo-total-menu-1.1.0.zip](https://github.com/georgyfr/woo-total-menu/releases/download/v1.1.0/woo-total-menu-1.1.0.zip)

## 🎯 Objectif de la version

Cette version démarre la **phase B (Builder UI React)** en mettant en place le squelette de l'application React qui sera utilisée pour éditer visuellement les menus Woo Total Menu.

Concrètement, en v1.1.0 :

- ✅ Le pipeline de build `@wordpress/scripts` est en place (Webpack 5 + Babel)
- ✅ La page admin "Builder" s'affiche en **full-screen** (menu WP et admin bar masqués)
- ✅ Le **layout 3 colonnes** est rendu (arborescence / aperçu / propriétés)
- ✅ Les **stores `@wordpress/data`** `wtm/menu` et `wtm/ui` sont opérationnels
- ✅ La communication avec l'API REST `/wtm/v1/menus` fonctionne via `@wordpress/api-fetch`
- ⏳ Le CRUD des items, le drag & drop et le live preview arriveront en v1.1.1 à v1.1.4

## ✅ Nouveautés (Added)

### 1. Pipeline de build `@wordpress/scripts`

**`package.json`** déclare :
- **Dépendances runtime** : `@wordpress/api-fetch`, `@wordpress/data`, `@wordpress/element`, `@wordpress/i18n`, `@wordpress/url`
- **devDependency** : `@wordpress/scripts` (Webpack 5 + Babel + DependencyExtractionWebpackPlugin)
- **Scripts npm** :
  - `npm run build` — Build production (sortie dans `build/`)
  - `npm run start` — Build dev avec watch
  - `npm run lint:js` — Lint ESLint WordPress
  - `npm run packages-update` — Mise à jour des packages `@wordpress/*`

**`webpack.config.js`** custom : override l'entry point par défaut (`src/index.js`) pour pointer vers `builder/index.js` (afin de séparer le code React du code PHP).

### 2. Sortie du build

```
build/
├── index.js             (14.3 Ko, minified)
├── index.asset.php      (dépendances générées pour WordPress)
├── style-index.css      (8.0 Ko, minified)
└── style-index-rtl.css  (8.0 Ko, RTL)
```

Le `DependencyExtractionWebpackPlugin` génère automatiquement `index.asset.php` qui liste les dépendances WordPress (par ex. `wp-element`, `wp-data`, `wp-api-fetch`, etc.) — c'est ce qui permet à WordPress de charger les scripts dans le bon ordre.

### 5. Stores `@wordpress/data`

#### `wtm/menu`

État du menu en cours d'édition.

| État | Description |
|------|-------------|
| `menu` | L'objet menu complet (depuis l'API REST) |
| `isLoading` | True pendant le chargement |
| `isSaving` | True pendant la sauvegarde |
| `isDirty` | True si des modifications non sauvegardées |
| `error` | Message d'erreur éventuel |

| Action | Description |
|--------|-------------|
| `loadMenu(menuId, defaultMenu)` | Charge un menu par ID via GET `/wtm/v1/menus/{id}` |
| `saveMenu()` | Sauvegarde via PUT (si menu existant) ou POST (si nouveau) |
| `updateMenuTitle(title)` | Met à jour le titre (marque dirty) |
| `updateMenuConfig(config)` | Met à jour la config (marque dirty) |
| `setMenu(menu)` | Définit directement le menu |
| `setError(error)` | Définit une erreur |
| `setDirty(isDirty)` | Marque comme dirty |

| Sélecteur | Retour |
|-----------|--------|
| `getMenu()` | L'objet menu |
| `getItems()` | Le tableau `config.items` |
| `getSelectedItem(itemId)` | Item trouvé par ID (récursif) |
| `isLoading()` / `isSaving()` / `isDirty()` / `getError()` | Booleans/strings |

#### `wtm/ui`

État de l'interface utilisateur.

| État | Description |
|------|-------------|
| `selectedItemId` | ID de l'item sélectionné dans l'arborescence |
| `device` | `desktop` / `tablet` / `mobile` |
| `restUrl` | URL de base de l'API REST |
| `restNonce` | Nonce WordPress pour auth REST |

| Action | Description |
|--------|-------------|
| `selectItem(itemId)` | Sélectionne un item |
| `setDevice(device)` | Change le device de preview |
| `setRestConfig({restUrl, restNonce})` | Configure REST |

### 6. Composants React

#### `App.js`
- Composant racine
- Reçoit `initialState` (depuis `wtmBuilderData` localisé par PHP)
- Sur mount : configure REST + charge le menu
- Rend `<Header>` + 3 colonnes
- Affiche les erreurs dans une barre dédiée

#### `Header.js`
- Titre du menu + indicateur "dirty" (●) si modifications non sauvegardées
- Badge du type de menu (horizontal/vertical/offcanvas/footer)
- Sélecteur de device (3 boutons icônes : desktop/tablet/mobile)
- Bouton "Enregistrer" (désactivé si !dirty ou isLoading)

#### `TreePanel.js`
- Liste les items avec récursivité (children)
- Icône par type : `link` → `admin-links`, `mega_container` → `screenoptions`, `column` → `columns`, `widget` → `admin-generic`, `title` → `heading`, `separator` → `minus`
- Badge affiché si présent
- Item sélectionné surligné en violet
- État vide avec message "Aucun élément pour l'instant"
- Bouton "+" en haut (désactivé — viendra en v1.1.2)

#### `PreviewPanel.js`
- Frame responsive : 100% / 768px / 375px selon le device
- Placeholder statique montrant un header fictif avec logo + nav + cart
- Si items présents, affiche les 5 premiers labels
- Si menu vide, message "Ajoutez des éléments dans l'arborescence"
- Spinner pendant le chargement

#### `PropertiesPanel.js`
- Si item sélectionné : affiche ses propriétés (id, type, label, url, widget_type, badge)
- Si aucun item sélectionné mais menu chargé : affiche les propriétés du menu (titre, slug, statut, type, location, version)
- Si aucun menu chargé : message d'aide

### 7. Page admin "Builder"

**`src/Admin/Pages/Builder.php`** :
- Sous-menu `wtm-builder` (capacité `wtm_manage_menus`)
- Lit `menu_id` et `new` depuis la query string
- Masque le menu admin WP et l'admin bar (CSS `display:none`)
- Rend le conteneur `<div id="wtm-builder-root" data-menu-id="..." data-is-new="...">`
- Le CSS `position: fixed` permet au builder d'occuper tout l'écran

**`Admin_Menu::enqueue_builder_assets()`** :
- Vérifie que `build/index.js` existe (sinon affiche un notice d'erreur)
- Lit les dépendances depuis `build/index.asset.php`
- Enregistre et enqueue `wtm-builder` (JS) + `wtm-builder-style` (CSS)
- Localise `wtmBuilderData` avec `restUrl` et `restNonce`

### 8. Bouton "Builder" sur la liste des menus

Sur la page `wtm-menus`, chaque ligne a maintenant un bouton violet "Builder" qui ouvre le builder pour le menu correspondant : `admin.php?page=wtm-builder&menu_id={id}`

## 🔧 Instructions de mise à jour

Depuis la v1.0.4 :
1. Désactivez le plugin dans WordPress
2. Remplacez le dossier `woo-total-menu/` par la nouvelle version
3. **Important** : si vous développez le plugin, exécutez `npm install && npm run build` dans le dossier du plugin pour générer les assets React. Le ZIP distribué inclut déjà le dossier `build/` compilé, donc cette étape n'est nécessaire que pour les développeurs.
4. Réactivez le plugin
