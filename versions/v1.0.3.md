## 🎯 Objectif de la version

Cette version expose une **API REST complète** pour gérer les menus Woo Total Menu par programme. Contrairement à l'API REST native WordPress (`/wp/v2/wtm_menus`) qui expose le CPT tel quel, notre API custom :

- retourne un **format de réponse propre** (sans internals WP comme `guid`, `_links`, `template`, etc.)
- décode les métadonnées JSON (`_wtm_config`, `_wtm_header_config`, `_wtm_footer_config`) en **vrais objets JSON** dans les réponses
- **valide le schéma** de chaque config avant sauvegarde
- expose une action **`/duplicate`** dédiée
- permet le **filtrage par type, emplacement, statut** via des query params dédiés

Cette API sera utilisée par le builder visuel React en v1.1.x.

## ✅ Nouveautés (Added)

### 1. Endpoints REST exposés

| Méthode | Endpoint | Description | Statut réussite |
|---------|----------|-------------|-----------------|
| `GET`   | `/wp-json/wtm/v1/menus` | Liste paginée avec filtres | 200 |
| `GET`   | `/wp-json/wtm/v1/menus/{id}` | Détail d'un menu | 200 |
| `POST`  | `/wp-json/wtm/v1/menus` | Création d'un menu | 201 + Location |
| `PUT`   | `/wp-json/wtm/v1/menus/{id}` | Mise à jour (partielle ou complète) | 200 |
| `PATCH` | `/wp-json/wtm/v1/menus/{id}` | Alias de PUT | 200 |
| `DELETE`| `/wp-json/wtm/v1/menus/{id}` | Suppression | 200 |
| `POST`  | `/wp-json/wtm/v1/menus/{id}/duplicate` | Duplication | 201 + Location |
| `GET`   | `/wp-json/wtm/v1/menus/schema` | Schéma JSON Schema complet | 200 |

### 2. Paramètres de la liste (GET /wtm/v1/menus)

| Paramètre | Type | Défaut | Description |
|-----------|------|--------|-------------|
| `page` | integer | 1 | Numéro de page (≥ 1) |
| `per_page` | integer | 20 | Nombre par page (1-100) |
| `search` | string | — | Recherche plein texte dans les titres |
| `menu_type` | string | — | Filtre par type (`horizontal`, `vertical`, `offcanvas`, `footer`) |
| `location` | string | — | Filtre par emplacement (`primary`, `footer`, `sidebar`, `mobile`) |
| `status` | string | `any` | Filtre par statut (`publish`, `draft`, `any`) |
| `orderby` | string | `date` | Tri (`date`, `modified`, `title`, `id`) |
| `order` | string | `desc` | Sens du tri (`asc`, `desc`) |

**En-têtes de réponse** :
- `X-WP-Total` : nombre total de menus correspondants
- `X-WP-TotalPages` : nombre total de pages

### 3. Champs acceptés en création/mise à jour

| Champ | Type | Requis en create | Défaut | Description |
|-------|------|------------------|--------|-------------|
| `title` | string | ✅ | — | Titre du menu |
| `slug` | string | — | auto | Slug URL |
| `status` | string | — | `publish` | `publish` ou `draft` |
| `menu_type` | string | — | `horizontal` | Type de menu |
| `location` | string | — | `primary` | Emplacement |
| `config` | object/string | — | `{"version":1,"items":[]}` | Configuration JSON du menu |
| `header_config` | object/string | — | `null` | Configuration JSON du header |
| `footer_config` | object/string | — | `null` | Configuration JSON du footer |
| `version` | integer | — | `WTM_DB_VERSION` | Version du schéma |

### 5. Classe `Schema_Validator` (`src/Core/Schema_Validator.php`)

Validation JSON pour les 3 méta-keys de configuration :

#### Pour `_wtm_config`
- `version` (integer, défaut 1)
- `items` (array, défaut [])
  - Chaque item doit avoir : `id` (string), `type` (parmi `link`, `mega_container`, `column`, `widget`, `title`, `separator`)
  - `children` (array optionnel, récursif)
- `settings` (object optionnel)

#### Pour `_wtm_header_config` et `_wtm_footer_config`
- `version` (integer, défaut 1)
- `rows` (array, défaut [])
- `settings` (object optionnel)

#### Méthodes publiques
- `validate_config($value)` → `true|WP_Error`
- `validate_item($item, $path)` → `true|WP_Error`
- `validate_layout($value)` → `true|WP_Error`
- `decode_and_validate_config($raw)` → `array|WP_Error`
- `decode_and_validate_layout($raw)` → `array|WP_Error`
- `normalize_config($value)` → `array`
- `normalize_layout($value)` → `array`

### 6. Sécurité

- **Permission** : tous les endpoints (lecture + écriture) requièrent la capacité `wtm_manage_menus`
- **Authentification** : cookie WordPress + nonce `X-WP-Nonce` (standard WP REST)
- **Sanitization** : chaque paramètre a son `sanitize_callback` dédié (sanitize_text_field, sanitize_key, absint, sanitize_title)
- **Cache** : invalidation automatique du cache du menu après chaque opération d'écriture (create, update, delete, duplicate)

### 7. Codes d'erreur

| Code HTTP | Code d'erreur | Description |
|-----------|---------------|-------------|
| 401 | `rest_not_logged_in` | Non connecté |
| 403 | `wtm_rest_forbidden` | Connecté mais sans la cap `wtm_manage_menus` |
| 400 | `wtm_missing_title` | Création sans titre |
| 400 | `wtm_invalid_json` | JSON mal formé |
| 400 | `wtm_invalid_config_type` | Config n'est pas un objet |
| 400 | `wtm_invalid_version` | `version` n'est pas un entier |
| 400 | `wtm_invalid_items` | `items` n'est pas un tableau |
| 400 | `wtm_invalid_item_type` | Type d'item non autorisé |
| 400 | `wtm_missing_item_id` | Item sans champ `id` |
| 400 | `wtm_invalid_children` | `children` n'est pas un tableau |
| 404 | `wtm_menu_not_found` | ID de menu inexistant ou mauvais type |
| 500 | `wtm_delete_failed` | Échec de la suppression |

## 🔧 Instructions de mise à jour

Depuis la v1.0.2 :
1. Désactivez le plugin dans WordPress
2. Remplacez le dossier `woo-total-menu/` par la nouvelle version
3. Réactivez le plugin

Aucune migration de données n'est nécessaire — la structure CPT et méta est inchangée. Les caps sont automatiquement ré-enregistrées sur `init`.

## 📖 Exemples d'utilisation (curl)

```bash
# Lister tous les menus
curl -b cookies.txt -H "X-WP-Nonce: <nonce>" \
  http://localhost:8080/wp-json/wtm/v1/menus

# Filtrer : menus verticaux en brouillon
curl -b cookies.txt -H "X-WP-Nonce: <nonce>" \
  "http://localhost:8080/wp-json/wtm/v1/menus?menu_type=vertical&status=draft"

# Créer un nouveau menu
curl -b cookies.txt -H "X-WP-Nonce: <nonce>" \
  -H "Content-Type: application/json" \
  -X POST -d '{
    "title": "Menu API",
    "menu_type": "horizontal",
    "location": "primary",
    "config": {"version":1,"items":[{"id":"i1","type":"link","label":"Accueil","url":"/"}]}
  }' \
  http://localhost:8080/wp-json/wtm/v1/menus

# Mettre à jour uniquement le titre
curl -b cookies.txt -H "X-WP-Nonce: <nonce>" \
  -H "Content-Type: application/json" \
  -X PUT -d '{"title":"Nouveau titre"}' \
  http://localhost:8080/wp-json/wtm/v1/menus/12

# Dupliquer
curl -b cookies.txt -H "X-WP-Nonce: <nonce>" \
  -X POST \
  http://localhost:8080/wp-json/wtm/v1/menus/12/duplicate

# Supprimer
curl -b cookies.txt -H "X-WP-Nonce: <nonce>" \
  -X DELETE \
  http://localhost:8080/wp-json/wtm/v1/menus/12
```
