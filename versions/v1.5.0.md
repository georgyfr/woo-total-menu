## 🎯 Objectif de la version

La phase **v1.4.0** a livré le Builder visuel de Headers et Footers globaux, finalisant la trinité Menu / Header / Footer du plugin. Restait une dernière friction utilisateur : **démarrer un menu/header/footer from scratch** prenait du temps, même avec les palettes et canevas en place.

La **v1.5.0** introduit une **bibliothèque de templates intégrés** (12 templates) avec une galerie visuelle accessible en un clic depuis le Builder. L'utilisateur peut désormais :

- Parcourir 12 templates prêts à l'emploi (4 menus, 4 headers, 4 footers) ;
- Filtrer par type, par catégorie métier (e-commerce, blog, corporate, minimal, electronics) et par recherche plein-texte ;
- Prévisualiser chaque template via un mini-aperçu CSS synthétique ;
- Appliquer un template en 1 clic (avec confirmation) — il écrase la configuration actuelle du menu et recharge le Builder.

Cette version s'inscrit dans la **phase v1.5.x — Templates** définie par la roadmap. Elle expose également un filtre `wtm_templates_catalog` permettant aux extensions tierces d'ajouter leurs propres templates.

| Fonctionnalité | Statut | Spec | Description |
|----------------|--------|------|-------------|
| 12 templates intégrés | Nouveau | §1.4.2 | 4 menus + 4 headers + 4 footers répartis en 5 catégories métier. |
| Template_Registry | Nouveau | §1.4.2 | Registre statique lazy-built, validation via Schema_Validator, application à un menu. |
| Templates_Controller | Nouveau | §1.4.2 | 3 routes REST : GET /templates, GET /templates/{id}, POST /templates/{id}/apply. |
| TemplateGallery (React) | Nouveau | §1.4.2 | Modal avec toolbar (tabs + recherche + catégories) et grille de cards. |
| TemplateCard (React) | Nouveau | §1.4.2 | Carte individuelle avec mini-aperçu CSS + bouton "Appliquer". |
| Store `wtm/templates` | Nouveau | §1.4.2 | Cache du catalogue, filtres, états d'application, action async `applyTemplate`. |
| UI store étendu | Upgrade | — | Nouvel état `isTemplatesOpen` + 2 actions. |
| Filtre `wtm_templates_catalog` | Nouveau | §1.4.2 | Hook développeur pour modifier le catalogue. |
| Action `wtm_template_applied` | Nouveau | §1.4.2 | Hook post-application pour réactions tierces. |

## ✨ Nouveautés

### 1. Backend PHP — `Template_Registry`

**`src/Core/Template_Registry.php`** (~840 lignes) — Registre centralisé des templates intégrés.

#### API publique

| Méthode | Description |
|---------|-------------|
| `Template_Registry::all()` | Renvoie le catalogue complet (12 templates). Cache statique lazy-built. |
| `Template_Registry::get($id)` | Récupère un template par slug. |
| `Template_Registry::by_type($type)` | Filtre par type (`menu` \| `header` \| `footer`). |
| `Template_Registry::categories()` | Renvoie les catégories distinctes avec compte. |
| `Template_Registry::apply_to_menu($menu_id, $template_id, $mode)` | Applique un template à un menu. Valide, sélectionne la meta cible, écrit, déclenche l'action. |

#### Catalogue des 12 templates

**Menus (4)** :

| ID | Nom | Description |
|----|-----|-------------|
| `menu-simple-horizontal` | Menu horizontal simple | 4 liens plats (Accueil, Boutique, Blog, Contact). Idéal blog/vitrine. |
| `menu-mega-mode` | Méga menu boutique de mode | 2 méga containers (Femmes, Hommes) avec colonnes liens + product_grid + banner promo. |
| `menu-mega-electronics` | Méga menu électronique | 3 méga containers (Smartphones, Ordinateurs, TV) + bannière promo high-tech. |
| `menu-vertical-sidebar` | Menu vertical sidebar | 3 catégories dépliables + widget `filters` WooCommerce. Pour sidebar catalogue. |

**Headers (4)** :

| ID | Nom | Description |
|----|-----|-------------|
| `header-ecommerce-classic` | Header e-commerce classique | 3 colonnes : Logo \| Menu \| Recherche + Panier + Compte. |
| `header-minimal` | Header minimaliste | 2 colonnes : Logo \| Menu. Pour blog/portfolio. |
| `header-promo-banner` | Header promotionnel | 2 lignes : top bar promo + ligne main (logo, menu, recherche, panier). |
| `header-sticky-centered` | Header sticky centré | 2 lignes : logo centré + menu centré. Style éditorial/luxe. |

**Footers (4)** :

| ID | Nom | Description |
|----|-----|-------------|
| `footer-ecommerce-4cols` | Footer e-commerce 4 colonnes | About + 2 menus + newsletter. Le footer e-commerce universel. |
| `footer-minimal` | Footer minimaliste | Copyright + icônes sociales. Pour blog/portfolio. |
| `footer-corporate-4cols` | Footer corporate 4 colonnes | Logo + description + 3 menus (Société, Légal, Ressources). Fond sombre #1A1A2E. |
| `footer-dark-accessible` | Footer sombre accessible WCAG AA | 4 colonnes sur fond #0F1419 + bottom bar RGPD. Contraste AA. |

#### Mécanique d'application

```php
$result = Template_Registry::apply_to_menu( $menu_id, $template_id, $mode );
// $mode : 'menu' | 'header' | 'footer'
// Sélection meta : _wtm_config | _wtm_header_config | _wtm_footer_config
// Validation : Schema_Validator::validate_config() (menu) ou validate_layout() (header/footer)
// Action : do_action( 'wtm_template_applied', $menu_id, $template_id, $mode, $template );
```

### 2. API REST — `Templates_Controller`

**`src/Api/Templates_Controller.php`** (~330 lignes) — 3 endpoints REST sous `/wtm/v1/templates`.

#### Endpoints

| Méthode | Route | Permission | Description |
|---------|-------|------------|-------------|
| `GET` | `/wtm/v1/templates` | Publique | Liste filtrable par `type`, `category`, `search`. |
| `GET` | `/wtm/v1/templates/{id}` | Publique | Détail d'un template avec `config` complète. |
| `POST` | `/wtm/v1/templates/{id}/apply` | `edit_posts` | Applique le template à un menu. Body : `{ menu_id, mode }`. |

#### Exemples

```bash
# Lister tous les templates
curl http://localhost:8080/wp-json/wtm/v1/templates

# Filtrer par type header
curl 'http://localhost:8080/wp-json/wtm/v1/templates?type=header'

# Filtrer par catégorie ecommerce
curl 'http://localhost:8080/wp-json/wtm/v1/templates?category=ecommerce'

# Recherche plein-texte
curl 'http://localhost:8080/wp-json/wtm/v1/templates?search=newsletter'

# Détail d'un template
curl http://localhost:8080/wp-json/wtm/v1/templates/header-ecommerce-classic

# Appliquer un template (avec authentification)
curl -X POST http://localhost:8080/wp-json/wtm/v1/templates/footer-ecommerce-4cols/apply \
  -H "X-WP-Nonce: $NONCE" \
  -H "Content-Type: application/json" \
  -d '{"menu_id": 42, "mode": "footer"}'
```

#### Schéma JSON public

Le schéma JSON-Schema draft-04 est exposé sur l'endpoint `/wp-json/wtm/v1/templates` via l'option `schema` de `register_rest_route`. Chaque template expose : `id`, `name`, `description`, `type`, `category`, `thumbnail`, `preview`, `tags`, `config` (uniquement sur `/templates/{id}`).

### 3. Builder React — Galerie de templates

#### Bouton "Galerie de templates"

Nouveau bouton dans le Header du Builder (entre "Historique des révisions" et le mode-switcher), avec icône `dashicons-layout`. Au clic, ouvre la modal `TemplateGallery`.

#### `TemplateGallery.js`

Modal plein écran (96vw, max 1100px) avec :

1. **Toolbar** :
   - 4 tabs type : `Tous` / `Menus` / `Headers` / `Footers` ;
   - Champ de recherche plein-texte (filter sur `name + description + preview + tags`) ;
2. **Filtre catégories** : chips cliquables avec compte par catégorie ;
3. **Grille de cards** : `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))` ;
4. **État empty / loading** : affichage dédié avec `Spinner` ;
5. **État applying** : bandeau en bas pendant l'application.

**Comportements** :
- À l'ouverture, pré-filtre automatiquement sur le mode actif (Header → tab Headers, Footer → tab Footers) ;
- Fermeture au clic sur la croix ou Escape (sauf si une application est en cours, `isDismissable={!isApplying}`) ;
- `shouldCloseOnClickOutside={false}` pour éviter les fermetures accidentelles.

#### `TemplateCard.js`

Carte individuelle avec :

1. **Mini-aperçu CSS** : 10 variants de thumbnails rendus en CSS pur (rectangles colorés) :
   - `menu-simple` : barre + 4 liens plats
   - `menu-mega` : row + grille 3 cols (1 large)
   - `menu-vertical` : sidebar verticale 4 items
   - `header-3cols` : Logo + links + icons
   - `header-2cols` : Logo + links
   - `header-2rows` : topbar + row
   - `header-centered` : 2 lignes centrées
   - `footer-4cols` : grille 4 cols
   - `footer-minimal` : text centré + 3 icons
   - `footer-dark` : cols + bottom bar sur fond #0F1419
2. **Badge type** : en haut à droite, "MENU" / "HEADER" / "FOOTER" avec icône dashicons ;
3. **Titre + description** + tooltip preview textuel ;
4. **Tags** (max 4) ;
5. **Bouton "Appliquer"** avec icône `dashicons-migrate`.

**Confirmation** : un `window.confirm()` est déclenché avant l'application (le template écrase la config actuelle).

### 4. Store Redux — `wtm/templates`

**`builder/stores/templates.js`** (~260 lignes) — Store dédié à la galerie.

#### État

```js
{
  templates: [],         // Catalogue (cache après premier fetch)
  isLoading: false,
  error: null,
  filterType: '',        // '' | 'menu' | 'header' | 'footer'
  filterCategory: '',    // '' | 'ecommerce' | 'blog' | ...
  filterSearch: '',      // free-text
  isApplying: false,
  applyError: null,
  lastApplied: null,     // { id, menu_id, mode, ts }
}
```

#### Actions

| Action | Type | Description |
|--------|------|-------------|
| `fetchTemplates({ force })` | Async | Fetch le catalogue via `apiFetch`. Idempotent (skip si déjà chargé). |
| `applyTemplate(id)` | Async | POST → reload menu → reload layout (si header/footer) → ferme la galerie. |
| `setFilterType(val)` | Sync | Filtre par type. |
| `setFilterCategory(val)` | Sync | Filtre par catégorie. |
| `setFilterSearch(val)` | Sync | Recherche plein-texte. |
| `resetFilters()` | Sync | Réinitialise les 3 filtres. |

#### Sélecteurs

| Sélecteur | Description |
|-----------|-------------|
| `getTemplates(state)` | Catalogue complet. |
| `getFilteredTemplates(state)` | Catalogue filtré par les 3 filtres actifs. |
| `getCategories(state)` | Catégories distinctes avec libellé traduit + compte. |
| `isLoading`, `getError`, `isApplying`, `getApplyError`, `getLastApplied` | États divers. |

### 5. Store `wtm/ui` étendu

Nouvel état `isTemplatesOpen` (boolean) + actions `openTemplates()` / `closeTemplates()` + sélecteur `isTemplatesOpen(state)`. Réduit dans `case 'SET_TEMPLATES_OPEN'`.

### 6. Hooks développeurs

#### Filtre `wtm_templates_catalog`

```php
add_filter( 'wtm_templates_catalog', function ( $catalog ) {
	$catalog[] = array(
		'id'          => 'my-extension-template',
		'name'        => __( 'Template personnalisé', 'my-extension' ),
		'description' => __( 'Ajouté par mon extension.', 'my-extension' ),
		'type'        => 'menu',
		'category'    => 'ecommerce',
		'thumbnail'   => 'menu-simple',
		'preview'     => 'Mon template',
		'tags'        => array( 'custom', 'extension' ),
		'config'      => array(
			'version' => 1,
			'items'   => array(
				array( 'id' => 'i1', 'type' => 'link', 'label' => 'Accueil', 'url' => '/' ),
			),
		),
	);
	return $catalog;
} );
```

#### Action `wtm_template_applied`

```php
add_action( 'wtm_template_applied', function ( $menu_id, $template_id, $mode, $template ) {
	// Ex : logger l'application, envoyer un webhook, mettre à jour un cache, etc.
	error_log( "Template $template_id applied to menu $menu_id (mode=$mode)" );
}, 10, 4 );
```

## 🚀 Installation et mise à jour

### Mise à jour depuis v1.4.0

Aucune migration de base de données nécessaire. La version v1.5.0 ajoute uniquement :

- 2 nouvelles classes PHP (autoloadées via PSR-4) ;
- 3 nouvelles routes REST (auto-enregistrées par le controller) ;
- 1 nouveau store Redux (enregistré au montage du Builder) ;
- 1 nouveau composant React (monté dans App.js).

Aucune option, meta ou table supplémentaire.

### Installation fraîche

1. Télécharger le ZIP : `https://github.com/georgyfr/woo-total-menu/releases/download/v1.5.0/woo-total-menu-1.5.0.zip` ;
2. Upload via `wp-admin → Extensions → Ajouter → Mettre une extension en ligne` ;
3. Activer le plugin ;
4. Aller dans `wp-admin → Woo Total Menu → Builder` pour un menu existant ;
5. Cliquer sur le bouton "Galerie de templates" (icône layout) dans le Header.

### Utilisation

1. Ouvrir le Builder pour un menu (ou en créer un nouveau).
2. Choisir le mode souhaité (Menu / Header / Footer) via les tabs du Header.
3. Cliquer sur "Galerie de templates".
4. La galerie s'ouvre pré-filtrée sur le mode actif.
5. Optionnellement : changer de tab type, filtrer par catégorie, ou rechercher.
6. Cliquer sur "Appliquer" sur le template souhaité.
7. Confirmer dans la boîte de dialogue.
8. Le Builder se recharge avec la nouvelle configuration.
