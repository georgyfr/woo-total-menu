- **Statut** : ✅ Livrée

## 🎯 Objectif de la version

Cette version introduit le **Custom Post Type `wtm_menu`** qui sera le cœur du plugin : tout menu, header ou footer créé avec Woo Total Menu sera stocké sous forme de post `wtm_menu` avec sa configuration JSON en métadonnée. La version ajoute également les méta-boxes d'édition dans l'admin WordPress standard et enregistre 4 emplacements de thème par défaut.

## ✅ Nouveautés (Added)

### 1. Custom Post Type `wtm_menu` (`src/Core/CPT_Manager.php`)
- CPT enregistré sur `init` priorité 5
- **REST-enabled** : accessible à `/wp-json/wp/v2/wtm_menus`
- **Révisions activées** (pour future fonctionnalité undo/redo)
- **Éditeur de blocs désactivé** (le builder visuel viendra en v1.1.x)
- **Capacités personnalisées** mappées sur `wtm_manage_menus` :
  - `edit_post`, `delete_post`, `edit_posts`, `delete_posts`, `publish_posts` → `wtm_manage_menus`
  - `read_post`, `read_private_posts` → `read`
- `map_meta_cap` à `true` pour que WordPress gère automatiquement les checks
- Caché du menu admin standard (`show_in_menu = false`) — sera exposé via nos propres pages en v1.0.2
- Icône : `dashicons-menu`
- Supporte : `title`, `author`, `revisions`, `custom-fields`

### 2. 4 types de menus (filterable via `wtm_menu_types`)
| Slug | Libellé |
|------|---------|
| `horizontal` | Méga menu horizontal |
| `vertical` | Menu vertical (sidebar) |
| `offcanvas` | Menu off-canvas |
| `footer` | Menu de pied de page |

### 3. 4 emplacements (locations) enregistrés comme `nav_menu_locations`
| Slug | Description |
|------|-------------|
| `wtm_primary` | Menu principal (header) |
| `wtm_footer` | Pied de page |
| `wtm_sidebar` | Barre latérale |
| `wtm_mobile` | Menu mobile dédié |

Les 4 locations sont enregistrées via `register_nav_menus()` et préfixées `[WTM]` pour les distinguer des emplacements natifs du thème.

### 4. 6 méta-keys enregistrées via `register_post_meta()`
Toutes les méta-keys sont REST-visibles et possèdent un callback de sanitization :

| Clé | Type | Défaut | REST | Sanitization |
|-----|------|--------|------|--------------|
| `_wtm_location` | string | `primary` | ✅ | Vérifie que la valeur fait partie des 4 locations |
| `_wtm_menu_type` | string | `horizontal` | ✅ | Vérifie que la valeur fait partie des 4 types |
| `_wtm_config` | JSON | `{"version":1,"items":[]}` | ✅ | Décode/re-encode le JSON pour valider |
| `_wtm_header_config` | JSON | (vide) | ✅ | JSON optionnel — vide autorisé |
| `_wtm_footer_config` | JSON | (vide) | ✅ | JSON optionnel — vide autorisé |
| `_wtm_version` | integer | `1` | ✅ | `absint()` |

Chaque méta a un `auth_callback` qui vérifie `current_user_can('wtm_manage_menus', $post_id)`.

### 5. Méta-boxes (`src/Admin/Meta_Boxes.php`)
Sur la page d'édition d'un menu (`wp-admin/post.php?post={id}&action=edit`), deux méta-boxes sont rendues :

**Sidebar** (`wtm_menu_settings`, contexte `side`, priorité `high`) :
- Sélecteur d'emplacement (4 options)
- Sélecteur de type de menu (4 options)
- Version du schéma (read-only)
- Note d'information sur le builder à venir

**Zone principale** (`wtm_menu_config`, contexte `normal`, priorité `high`) :
- Textarea pour `_wtm_config` (JSON principal)
- Textarea pour `_wtm_header_config` (optionnel)
- Textarea pour `_wtm_footer_config` (optionnel)

### 6. Sauvegarde sécurisée
- Vérification du nonce `wtm_meta_nonce` (action `wtm_save_meta`)
- Vérification de la capacité `wtm_manage_menus`
- Skip de l'autosave (`DOING_AUTOSAVE`)
- Sanitization de chaque champ
- **Invalidation du cache** du menu après sauvegarde via `Cache_Manager::invalidate_menu()`

### 7. Filtre `wp_insert_post_data`
- Garantit qu'un menu a toujours un titre non vide (sinon "Menu sans titre #{ID}")

## 🔧 Instructions de mise à jour

Depuis la v1.0.0 :
1. Désactivez le plugin dans WordPress
2. Remplacez le dossier `woo-total-menu/` par la nouvelle version
3. Réactivez le plugin

Aucune migration de données n'est nécessaire — la v1.0.0 n'avait créé aucune table ni post.
