- **Date de sortie** : 2026-06-24
- **Statut** : ✅ Livrée
- **Tag Git** : [`v1.0.2`](https://github.com/georgyfr/woo-total-menu/releases/tag/v1.0.2)
- **ZIP de release** : [woo-total-menu-1.0.2.zip](https://github.com/georgyfr/woo-total-menu/releases/download/v1.0.2/woo-total-menu-1.0.2.zip)

## 🎯 Objectif de la version

Cette version déploie l'**interface d'administration complète** du plugin :
- un **tableau de bord** avec statistiques et menus récents
- une **liste des menus** filtrable avec actions (créer, modifier, dupliquer, activer/désactiver, supprimer)
- une page de **réglages globaux** à 7 onglets (général, styles, typographie, responsive, performance, analytics, permissions)
- un **menu admin structuré** avec 4 sous-menus

L'utilisateur peut désormais gérer ses menus entièrement depuis l'interface dédiée (sans passer par l'écran standard "Tous les articles" de WordPress).

## ✅ Nouveautés (Added)

### 1. Menu admin structuré (`src/Admin/Admin_Menu.php`)
La classe `Admin_Menu` remplace l'ancien menu top-level unique par une hiérarchie complète :

```
Woo Total Menu
├─ Tableau de bord      (wtm-dashboard)   — wtm_manage_menus
├─ Menus                (wtm-menus)       — wtm_manage_menus
├─ Réglages             (wtm-settings)    — wtm_manage_settings
└─ À propos             (wtm-about)       — wtm_manage_menus
```

Le menu top-level pointe sur le tableau de bord. Chaque sous-menu a sa propre capacité requise, ce qui permet de donner accès à certains rôles sans tout débloquer.

### 2. Page Tableau de bord (`src/Admin/Pages/Dashboard.php`)
Vue d'ensemble avec :

- **6 cartes statistiques** :
  - Menus totaux (compteur)
  - Menus actifs (publiés)
  - Brouillons
  - Emplacements (répartition par location)
  - Types de menus (répartition par type)
  - Environnement (PHP, WP, WooCommerce, thème, DB version)

- **Boutons d'action rapide** :
  - "Créer un nouveau menu"
  - "Voir tous les menus"

- **Tableau des 5 menus récents** :
  - Titre, type (badge coloré), emplacement, statut, date de modification, action "Modifier"

- **Affichage des notifications** (succès/erreur) selon les paramètres d'URL :
  - `wtm_deleted`, `wtm_duplicated`, `wtm_toggled`

### 3. Page Liste des menus (`src/Admin/Pages/Menus_List.php`)
Table WordPress standard avec :

- **Filtres** (barre supérieure) :
  - Par type (Tous / horizontal / vertical / offcanvas / footer)
  - Par statut (Tous / Actifs / Brouillons)
  - Recherche texte

- **Colonnes** :
  - Titre (+ ID en sous-texte)
  - Type (badge coloré selon le type)
  - Emplacement (label lisible)
  - Statut (Actif / Inactif)
  - Date de création
  - Date de modification
  - Actions (4 boutons icônes)

- **Actions par ligne** (avec icônes) :
  - ✏️ Modifier (redirige vers `post.php?action=edit`)
  - 👁️ Activer/Désactiver (bascule `publish` ↔ `draft`)
  - 📄 Dupliquer (crée une copie avec méta + "(copie)" dans le titre)
  - 🗑️ Supprimer (avec confirmation JavaScript)

- **État vide** : si aucun menu n'existe, affiche un CTA "Créer mon premier menu"

- **Bouton "Créer un nouveau menu"** en haut de page

### 4. Page Réglages (`src/Admin/Pages/Settings.php`)
Formulaire d'édition de l'option `wtm_global_settings` avec **7 onglets** :

#### Onglet Général
- Checkbox "Activer Woo Total Menu sur le site"
- Select "Emplacement par défaut pour les nouveaux menus"

#### Onglet Styles
- 5 color pickers : primaire, fond, texte, succès, erreur
- 1 input number : arrondi des coins (0-50 px)

#### Onglet Typographie
- Select police (10 polices Google Fonts : Inter, Roboto, Open Sans, Lato, Montserrat, Poppins, Source Sans Pro, Nunito, Raleway, system-ui)
- 2 input number : taille de base (10-24 px), taille des titres (14-36 px)

#### Onglet Responsive
- 2 input number : breakpoint mobile (320-1200 px), breakpoint tablette (600-1400 px)
- Select comportement mobile : offcanvas / accordion / dropdown
- Select position hamburger : droite / gauche

#### Onglet Performance
- 3 checkboxes : cache activé, lazy load widgets, minify CSS

#### Onglet Analytics
- 2 checkboxes (désactivées — preview pour v1.7.1) :
  - "Activer la collecte d'analytics"
  - "Tracker également les utilisateurs connectés"

#### Onglet Permissions
- Tableau matriciel Rôles × Capacités (4 caps × tous les rôles WP)
- Checkbox pour attribuer/retirer chaque cap à chaque rôle
- L'administrateur a toutes les cases cochées et grisées (toujours full-access)

#### Sauvegarde
- Nonce `wtm_save_settings` vérifié
- Vérification capacité `wtm_manage_settings`
- Sanitization par champ (sanitize_hex_color, absint, sanitize_key, sanitize_text_field)
- Pour les permissions : `add_cap` / `remove_cap` sur chaque rôle
- Mise à jour de `version` et `db_version` dans les settings
- Redirection avec paramètre `wtm_settings_saved=1` (évite la resoumission au refresh)

### 5. Actions routées via `admin_init` (`Admin_Menu::handle_actions()`)
Pour permettre des redirections propres après action, toutes les actions passent par `admin.php?page=...&wtm_action=...&_wpnonce=...` et sont interceptées sur `admin_init` :

| Action | Effet | Paramètres requis |
|--------|-------|-------------------|
| `create_menu` | Crée un post `wtm_menu` + meta + redirige vers l'éditeur | `menu_type`, `location`, `menu_title` |
| `delete_menu` | Supprime un menu (`wp_delete_post`) | `menu_id` |
| `duplicate_menu` | Copie le menu + toutes ses méta | `menu_id` |
| `toggle_status` | Bascule `publish` ↔ `draft` | `menu_id` |

Chaque action :
- Vérifie la capacité `wtm_manage_menus`
- Vérifie le nonce `wtm_action_{action}`
- Effectue l'action
- Invalide le cache du menu concerné
- Redirige avec un paramètre de notification (`wtm_deleted`, `wtm_duplicated`, `wtm_toggled`)

### 6. Styles CSS partagés (`Admin_Menu::get_admin_css()`)
~120 lignes de CSS en ligne (injectées via `wp_add_inline_style`) partagées par toutes les pages WTM :

- Layout `.wtm-page`, `.wtm-grid`, `.wtm-card`, `.wtm-card-stat`, `.wtm-card-label`
- Notifications `.wtm-notice.is-success`, `.is-error`, `.is-warning`
- Boutons `.wtm-btn` (primaire, secondary, danger) avec hover
- Tables `.wtm-table` (header gris clair, hover row)
- Badges `.wtm-badge.is-{horizontal,vertical,offcanvas,footer,active,inactive}`
- Onglets `.wtm-tabs` + `.wtm-tabs a.is-active`
- Formulaire `.wtm-form-row`, `.wtm-form-section`
- État vide `.wtm-empty-state`

  - Ajout de la carte "Liens utiles" avec liens GitHub

## 🔧 Instructions de mise à jour

Depuis la v1.0.1 :
1. Désactivez le plugin dans WordPress (Extensions → Installées → Woo Total Menu → Désactiver)
2. Remplacez le dossier `woo-total-menu/` par la nouvelle version
3. Réactivez le plugin

Aucune migration de données n'est nécessaire. Les options `wtm_global_settings` et `wtm_db_version` sont conservées. Les caps sont automatiquement ré-enregistrées sur `init`.
